# VIOLET Face Studio

เว็บไซต์ทดลองวิเคราะห์รูปทรงและสัดส่วนใบหน้าจากกล้องหน้า โดยใช้ธีมสีดำ–ม่วง

## คุณสมบัติ

- เปิดกล้องหน้าและแสดงภาพตัวอย่างแบบเรียลไทม์
- ตรวจจับจุดสำคัญบนใบหน้าด้วย MediaPipe Face Landmarker
- ประเมินรูปทรงใบหน้าและอัตราส่วนบางส่วนจากจุดที่ตรวจพบ
- แสดงจุดตรวจจับบนภาพและเสนอไอเดียทรงผมทั่วไป
- ประมวลผลภาพจากกล้องในเบราว์เซอร์ โดยหน้าเว็บนี้ไม่มีโค้ดส่งภาพถ่ายไปยังเซิร์ฟเวอร์

## วิธีเริ่มใช้งาน

1. ดาวน์โหลด `violet_face_studio.html`
2. เปิดไฟล์ผ่านเว็บเซิร์ฟเวอร์ในเครื่อง (localhost) หรือโฮสต์บนเว็บไซต์ที่ใช้ HTTPS
3. เปิดหน้าเว็บด้วยเบราว์เซอร์รุ่นใหม่ เช่น Chrome หรือ Edge
4. กด **เปิดกล้อง** และอนุญาตสิทธิ์การใช้กล้องเมื่อเบราว์เซอร์ถาม
5. จัดใบหน้าให้อยู่กลางภาพและมีแสงเพียงพอ จากนั้นกด **วิเคราะห์ใบหน้า**
6. กด **ปิดกล้อง** เมื่อใช้งานเสร็จ

> การเข้าถึงกล้องโดยทั่วไปต้องใช้ secure context เช่น HTTPS หรือ localhost การเปิดไฟล์โดยตรงอาจไม่รองรับในบางเบราว์เซอร์

## การเชื่อมต่ออินเทอร์เน็ต

เว็บไซต์โหลดไลบรารี MediaPipe และโมเดลตรวจจับใบหน้าจาก CDN/แหล่งจัดเก็บภายนอกในครั้งแรก จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้ระบบวิเคราะห์เริ่มทำงานได้

## ความเป็นส่วนตัว

- ภาพจากกล้องถูกใช้ภายในหน้าเว็บเพื่อวิเคราะห์และแสดงผล
- โค้ดของเว็บไซต์นี้ไม่ได้อัปโหลดภาพถ่ายไปยังเซิร์ฟเวอร์
- ไลบรารีและไฟล์โมเดลถูกดาวน์โหลดจากผู้ให้บริการภายนอกตาม URL ที่ระบุในไฟล์ HTML
- เว็บไซต์นี้ไม่มีระบบบันทึกภาพหรือระบุตัวบุคคล

## ข้อจำกัด

ผลลัพธ์เป็นการประเมินคร่าว ๆ จากภาพเดียว ไม่ใช่การวัดทางการแพทย์หรือการยืนยันอัตลักษณ์ มุมกล้อง แสง สีหน้า การเอียงศีรษะ และการบังใบหน้าอาจทำให้ผลคลาดเคลื่อนได้ คำแนะนำทรงผมเป็นเพียงไอเดีย ไม่ใช่ข้อสรุปว่าทรงใดเหมาะสมที่สุด

## การแก้ปัญหาเบื้องต้น

- **เปิดกล้องไม่ได้:** ตรวจสอบสิทธิ์กล้องของเว็บไซต์ และปิดแอปอื่นที่กำลังใช้กล้อง
- **ไม่มีภาพจากกล้อง:** ตรวจสอบว่าเลือกกล้องที่ถูกต้องและใช้ HTTPS หรือ localhost
- **ไม่พบใบหน้า:** หันหน้าตรงเข้าหากล้อง เพิ่มแสง และขยับใบหน้าให้อยู่กลางภาพ
- **โมเดลโหลดไม่สำเร็จ:** ตรวจสอบการเชื่อมต่ออินเทอร์เน็ตและลองรีเฟรชหน้าเว็บ
